# Overview

Managing shared expenses in multi-tenant environments consistently resulted in lost receipts, manual spreadsheet reconciliation, and interpersonal friction. The goal was to build a system that made cost distribution automatic, transparent, and instantly verifiable for all roommates.

# Architecture

We evaluated a microservices approach but determined the operational overhead outweighed the benefits for our team size. Instead, we chose a modular monolith in NestJS. This allowed us to strictly enforce domain boundaries between User, Room, and Expense contexts via clear interfaces, retaining the ability to split into microservices later while keeping current deployments simple.

# Challenges

Implementing a lock-free distributed ledger was complex. We initially faced race conditions when multiple roommates submitted expenses simultaneously. We resolved this by implementing optimistic concurrency control using version numbers on the ledger rows, coupled with PostgreSQL's serializable isolation level for critical balance aggregation paths.

# Future Improvements

The system achieved our goal, reducing manual reconciliation time by 40% and successfully processing 10k concurrent transactions during peak end-of-month windows. In hindsight, I would have integrated an event sourcing pattern for the ledger from day one, which would have made producing an audit trail significantly simpler than our current trigger-based approach.
