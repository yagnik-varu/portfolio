# Overview

SpendSync V2 is a comprehensive room expense management platform designed to track, calculate, and distribute shared costs among roommates automatically. 

# Architecture

The system is built as a Modular Monolith using NestJS on the backend, ensuring distinct domain boundaries while maintaining deployment simplicity.

# Database Design

The data layer utilizes PostgreSQL deployed on Neon, featuring an isolated schema design for multi-tenancy at the room level.

# Future Improvements

Future iterations will focus on integrating automated bank feeds and implementing a robust event-driven notification system.
